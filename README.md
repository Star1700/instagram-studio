# Instagram Studio

Ein Dashboard für Instagram-Beiträge: Texte schreiben, Bilder oder Videos hinzufügen und Beiträge veröffentlichen oder planen.

## Installation

Voraussetzungen: Windows 11 und Codex mit ChatGPT-Anmeldung.

Gib Codex den Repository-Link und diesen Auftrag:

> Installiere Instagram Studio auf diesem PC. Lies docs/SETUP_WINDOWS.md und führe notebook/install-studio.ps1 aus.

Der Installer richtet Studio ein und erstellt eine Desktop-Verknüpfung. Verbinde anschließend ein Instagram-Creator- oder Business-Konto im Dashboard.
